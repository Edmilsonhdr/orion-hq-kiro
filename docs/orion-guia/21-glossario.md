# Glossário

Os termos usados no Orion, em ordem alfabética.

| Termo | Significado |
|---|---|
| **Adesão** | Quanto o paciente está seguindo as metas e o plano. Aparece em percentual na lista de pacientes e na Visão geral |
| **Alerta** | Aviso gerado pelo Orion para chamar a atenção do profissional: inatividade (mais de 48 horas sem registro) ou desvio nutricional. Pode ser resolvido ou adiado |
| **Anamnese** | Formulário de avaliação do paciente. Pode ser preenchida na consulta ou respondida pelo paciente no app |
| **Antropometria** | Medidas do corpo (circunferências e dobras cutâneas), das quais o Orion calcula índices como IMC e relação cintura-quadril |
| **Aluno** | O paciente da Educação Física |
| **Área** | Nutrição ou Educação Física. Define o que o profissional enxerga e usa |
| **Aviso** | Mensagem do profissional para o paciente na caixa de avisos do app (por exemplo, "plano atualizado"). Não traz dado clínico |
| **Código de convite** | Código `OR-XXXXXX` de cada profissional. O paciente que já tem conta o digita para se vincular |
| **Comi isso** | Botão do plano no app para registrar a refeição do plano em poucos toques |
| **Copiloto** | O assistente de IA do Orion, com o qual o paciente conversa no app |
| **Escudo** | Proteção da sequência: o paciente ganha 1 a cada 10 dias seguidos de registro (máximo 3) e perde 1 ao pular um dia |
| **Ficha de treino** | O treino montado pelo educador físico, com divisões, exercícios, séries, repetições, carga e descanso |
| **Ficha do paciente** | A tela central do atendimento, com as abas Visão analítica, Prontuário, Plano alimentar, Diário, Rotina, Evolução e Exames |
| **InBody** | Exame de bioimpedância. O Orion lê o PDF e guarda as medidas de composição corporal |
| **Macros** | Calorias, proteína, carboidrato e gordura. São sempre calculados pelo sistema |
| **Modelo** | Protocolo, plano alimentar, ficha de treino ou anamnese reaproveitável, privado ou compartilhado com a clínica |
| **Onboarding** | As cinco perguntas iniciais que o paciente responde no primeiro acesso ao app |
| **Origem dos macros** | De onde veio o número: Tabela TACO, TACO + IA, estimado pela IA ou manual (revisado pelo profissional) |
| **PAR-Q** | Questionário de prontidão para atividade física, com 7 perguntas, na anamnese do educador |
| **Plano alimentar** | O que comer em cada refeição. Pode estar em rascunho, ativo ou arquivado |
| **Protocolo** | O objetivo e as metas do paciente (calorias, proteína, carboidrato, gordura, hidratação), com as diretrizes de acompanhamento. Cada mudança é uma nova versão |
| **Receita** | Modo de preparo de uma refeição do plano. Só aparece para o paciente depois de liberada |
| **Retenção** | Faixa que mostra o quanto o aluno está treinando: Engajado, Oscilando, Em risco, Abandono, Recuperado, Começando ou Sem ficha |
| **Resumo cruzado** | Cartão da ficha que mostra o que a outra área registrou do mesmo paciente |
| **Sequência (streak)** | Número de dias seguidos em que o paciente registrou |
| **Sinal** | Ponto de atenção que o Orion percebe no comportamento do paciente, calculado nos últimos 14 dias. Há 23 sinais, de gravidade alta, média ou baixa |
| **Tabela TACO** | Tabela brasileira de composição de alimentos (591 alimentos), usada para calcular os macros |
| **Teleconsulta** | Consulta online, com link de sala e botão **Entrar** |
| **Vínculo** | A ligação entre profissional e paciente que permite ao profissional ver os dados dele |
